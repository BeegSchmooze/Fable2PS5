# game/

Put your own files here before running the build:

- `default.xex` — from your own copy of Fable II (Xbox 360). Required. The build checks its SHA-256.
- `cover.png` — optional. Any image you own; it becomes the PS5 home-screen icon. Without it a plain
  placeholder icon is used.

Nothing in this folder is ever committed (see `.gitignore`).
